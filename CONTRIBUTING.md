# Katkıda Bulunma Rehberi

Projeye katkıda bulunmak istediğiniz için teşekkürler! Bu proje açık kaynaklı bir eğitim materyalidir ve herkesin katkısına açıktır.

## Nasıl Katkıda Bulunabilirim?

1. **Repoyu Forklayın**: Bu repoyu kendi GitHub hesabınıza forklayın.
2. **Branch Oluşturun**: Yapacağınız değişiklikler için yeni bir dal (branch) oluşturun.
   ```bash
   git checkout -b ozellik/yeni-ozellik
   ```
3. **Değişiklikleri Yapın**: Kodunuzu veya dokümantasyonu düzenleyin.
4. **Commit Atın**: Yaptığınız değişiklikleri açıklayıcı bir mesajla kaydedin.
   ```bash
   git commit -m "Yeni: X özelliği eklendi"
   ```
5. **Push Edin**: Değişiklikleri kendi forkladığınız repoya gönderin.
   ```bash
   git push origin ozellik/yeni-ozellik
   ```
6. **Pull Request (PR) Açın**: Ana repoya bir Pull Request gönderin ve değişikliklerinizi açıklayın.

## Kurallar

- Kodunuzun çalışır durumda olduğundan emin olun.
- Mevcut kod düzenine ve isimlendirme standartlarına uyun.
- Eğitim materyali olduğu için açıklamaların anlaşılır olmasına özen gösterin.
- Herhangi bir sorunuz varsa "Issues" kısmından bize ulaşabilirsiniz.

Teşekkürler! 🎉
