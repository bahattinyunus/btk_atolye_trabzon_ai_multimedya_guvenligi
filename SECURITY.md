# 🛡️ Güvenlik Politikası

## Desteklenen Sürümler

Şu anda sadece projenin en son sürümü güvenlik güncellemeleri ile desteklenmektedir.

| Sürüm | Destekleniyor mu? |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Güvenlik Açığı Bildirme

Lütfen güvenlik açıklarını halka açık "Issue" bölümünde **BİLDİRMEYİN**.

Eğer bir güvenlik açığı bulursanız, veya şüpheli bir kod davranışı fark ederseniz:

1.  Lütfen repo sahibine doğrudan ulaşın veya GitHub üzerinden **Private Vulnerability Reporting** özelliğini kullanın (eğer aktifse).
2.  Bildiriminiz **48 saat** içinde incelenecek ve size dönüş yapılacaktır.
3.  Güvenlik açığı doğrulandığında, bir yama yayınlanacak ve katkınız için teşekkür edilecektir.
